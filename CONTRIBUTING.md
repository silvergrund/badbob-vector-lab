# Contributing

Run `npm ci`, then `npm test`, `npm run check` and `npm run build`. Use `npm run dev` to inspect the demo.

- Keep each component responsible for one effect. Use the existing components and demo as examples.
- Keep new effects independent and demonstrate them on a page under `src/pages/`.
- Keep motion pausable and respect reduced-motion preferences. Check desktop, mobile and the static fallback.
- Use HTML, SVG and CSS where practical. Discuss new runtime dependencies before adding them.
- Keep pull requests focused. Describe the behavior, checks and any visual differences; include screenshots for visual changes.
- Include only artwork and code you are allowed to share. Keep generated output and dependencies out of commits.

By contributing, you agree that your contribution is available under this repository's MIT license.
